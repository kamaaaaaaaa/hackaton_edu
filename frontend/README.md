# Готов к толчку — фронтенд

Веб-приложение для подготовки жителей Алматы к землетрясению.
Пользователь вводит адрес → видит риск своего дома на карте → находит ближайший
пункт сбора и маршрут → собирает «семейный круг» с общей точкой встречи → проходит
чек-лист готовности. Есть демо-режим тревоги.

Это **самостоятельное SPA** в папке `frontend/`. Django-бэкенд в корне репозитория
живёт отдельно; связь с ним — через слой `src/api/` (см. [`API_CONTRACT.md`](API_CONTRACT.md)).

## Стек

- **React 18 + Vite 5 + TypeScript**
- **Tailwind CSS** (светлая тема, без dark mode)
- **Leaflet + react-leaflet** — карта, тайлы OpenStreetMap (приглушены под светлый минимализм)
- **Nominatim** (OpenStreetMap) — поиск адреса, с debounce (≤ 1 запрос/сек)
- **vite-plugin-pwa** — офлайн-манифест и service worker
- Роутинг — `react-router-dom`. Внешних UI-библиотек нет.

## Быстрый старт

```bash
cd frontend
npm install
cp .env.example .env      # по умолчанию VITE_USE_MOCKS=true — бэкенд не нужен
npm run dev
```

Откроется на `http://localhost:5173`.

### Скрипты

| Команда           | Что делает                                    |
| ----------------- | --------------------------------------------- |
| `npm run dev`     | Дев-сервер с HMR                              |

См. [`.env.example`](.env.example):

| Переменная        | Значение по умолчанию            | Назначение                              |
| ----------------- | -------------------------------- | --------------------------------------- |
| `VITE_USE_MOCKS`  | `true`                           | `true` — моки, `false` — реальный API   |

## Экраны

1. **Главная** — лендинг: сильный заголовок, суть проблемы, CTA «Проверить мой дом».
2. **Карта** — поиск адреса с подсказками, маркер дома, пункты сбора, подсветка
   ближайшего, линия маршрута, расстояние и время пешком.
3. **Карточка дома** — этажность, год, тип, уровень риска (зелёный/жёлтый/красный) с пояснением.
4. **Семейный круг** — члены семьи (имя, телефон), точка встречи, статусы, кнопка «Я в порядке».
5. **Чек-лист готовности** — 15 пунктов с прогресс-баром «Индекс готовности».
6. **Баннер тревоги** — полноэкранное предупреждение + кнопка маршрута. Кнопка «Симулировать тревогу» в шапке.

## Что замокано / хранится локально

- **Пункты сбора** — `src/mocks/assemblyPoints.json` (18 реальных открытых площадок
  Алматы; координаты приблизительные).
- **Дом и риск** — детерминированная эвристика `src/lib/risk.ts` по адресу+координатам
  (реального реестра зданий у фронта нет; поле `estimated: true`). Один адрес всегда
  даёт один и тот же результат.
- **Семейный круг** и **чек-лист** — `localStorage` (ключи с префиксом `gkt.`).
- **Тревога** — в демо поднимается кнопкой; в проде придёт от бэкенда/МЧС.
- **Поиск адреса** — живой запрос в Nominatim (нужен интернет).

## Локализация

Интерфейс на русском, есть переключение на казахский (`RU ↔ ҚАЗ` в шапке).
Словари — `src/i18n/ru.ts` и `src/i18n/kk.ts` (ключи синхронизированы типами).
Выбор языка сохраняется в localStorage. Название продукта «Готов к толчку»
остаётся неизменным в обоих языках.

## Дизайн

- Минимализм + футуризм, mobile-first, только светлая тема.
- Палитра: белый/светло-серые фоны, акцент — **navy** (глубокий синий), «искра» —
  яркий синий на микро-детали; красный — тревога/высокий риск, зелёный — «в безопасности».
- Шрифты: **Manrope** (заголовки), **Inter** (текст) — Google Fonts.
- Логотип-вордмарк со знаком-пульсом сейсмографа; он же favicon и PWA-иконка.

## PWA

`vite-plugin-pwa` генерирует манифест и service worker (`registerType: autoUpdate`).
Тайлы карты кэшируются (CacheFirst) для более быстрого повторного открытия.
Иконки — SVG (`public/pwa-icon.svg`, `public/pwa-maskable.svg`).

## Связь с бэкендом

Бэкенд пишется отдельно. Форматы, которые ждёт фронтенд, описаны в
[`API_CONTRACT.md`](API_CONTRACT.md). Чтобы переключиться на реальный API:
`VITE_USE_MOCKS=false` и корректный `VITE_API_URL` в `.env`.
