# Готов к толчку — фронтенд

Веб-приложение, которое помогает жителям Алматы подготовиться к землетрясению:
найти свой дом и понять его риск, увидеть пеший маршрут до **официального**
пункта приёма населения, собрать семью в один круг и потренироваться.

---

## Для жюри: как запустить за 2 минуты

**Вариант 1. Открыть онлайн:** https://hackathon-base.onrender.com
(бесплатный Render засыпает — первое открытие может занять до минуты).

**Вариант 2. Запустить у себя** (нужен Node.js 18+):

```bash
cd frontend
npm install
npm run dev
```

Откройте http://localhost:5173. **Ключи и `.env` не нужны**: карта, поиск и
маршруты работают на открытых сервисах OpenStreetMap. Запросы к бэкенду
(`/api/...`) dev-сервер сам проксирует на сервер команды на Render.

Продакшн-сборка локально: `npm run build && npm run preview` → http://localhost:4173.

### Что посмотреть за 60 секунд

1. **Карта** → нажмите «Дома из списка» или введите `Сатпаева 24`.
   Дом поднимается в 3D цветом риска, строится пеший маршрут к самому быстрому
   из 5 ближайших официальных пунктов. Ниже — шаги «как в навигаторе»:
   нажмите шаг, и карта покажет этот участок. Кнопка **3D** справа наклоняет карту.
   Кнопка **×** убирает адрес и маршрут.
2. **Дома** → 14 реальных домов из OpenStreetMap: этажность, год, материал,
   время до пункта и **ИИ-разбор** (Claude): что это значит и что сделать.
3. **Семья** → создайте семью: телефон форматируется сам (`+7 (7XX) XXX-XX-XX`),
   код семьи — 6 клеток. Если сервер семьи недоступен, включается честный
   демо-режим на устройстве.
4. **Тревога · демо** (красная кнопка в шапке) → экран оповещения с таймером
   и кнопкой «Маршрут к пункту приёма».
5. Переключатель языка с флагом в шапке: **RU / KK**.
6. На телефоне сайт можно установить как приложение (PWA). Последний маршрут
   доступен офлайн.

| Дома | OpenStreetMap: `building:levels`, `start_date`, `building:material`, у каждого ссылка `way/ID` | 14 |
| Пешие маршруты | Valhalla (OpenStreetMap, пешеходный профиль, шаги на русском) | живой расчёт + запасной маршрут для домов из списка |
| ИИ-разбор домов | Claude (Anthropic) по данным дома и маршрута | подписан как ИИ, «не официальное заключение» |

**Оценка риска** — прозрачная формула ([`src/lib/risk.ts`](src/lib/risk.ts)),
на экране видно, из чего сложились баллы:

- **год постройки:** до 1957 +3 · 1957–1981 +2 · 1982–2006 +1 · позже 0;
- **материал стен:** кирпич, камень или саман +2 · панели или блоки +1 · монолит 0;
- **этажность:** выше 9 этажей +1.

Итог: 0–1 — низкий, 2–3 — средний, 4 и больше — высокий. Если нет ни года,
ни материала, пишем «недостаточно данных». Везде стоит пометка
«Предварительная оценка, не официальное заключение».

Пункты на проверке (адрес не подтверждён — на карте не показываем):

## Как фронтенд связан с бэкендом

```
Браузер ──/api/...──▶ Django (Render) ── БД
   │
   ├─ карта: tiles.openfreemap.org (OSM)
   ├─ поиск: photon.komoot.io → nominatim.openstreetmap.org
   └─ маршруты: valhalla1.openstreetmap.de
```

- Все запросы к бэкенду идут на **`/api`** — тот же домен, поэтому CORS не нужен.
- **Разработка:** `npm run dev` — Vite проксирует `/api` на
  `VITE_DEV_API_PROXY` (по умолчанию `https://hackathon-base.onrender.com`).
  Чтобы работать с локальным Django: `VITE_DEV_API_PROXY=http://127.0.0.1:8000`.
- **Продакшн:** Django на Render отдаёт собранный фронтенд из `frontend_dist/`
  и API с того же домена. Чтобы выкатить новую версию фронтенда:

  ```bash
  cd frontend
  npm run build:django   # собирает в ../frontend_dist
  ```

  Затем закоммитьте `frontend_dist/` и задеплойте: на Render нет Node.js,
  поэтому собранные файлы лежат в репозитории.
- Контракт эндпоинтов — [`API_CONTRACT.md`](API_CONTRACT.md).

## Стек

- React 18, Vite 5, TypeScript (strict), Tailwind CSS с дизайн-токенами.
- MapLibre GL 6: векторная карта OpenFreeMap (стиль Liberty в нашей палитре),
  3D-дома, анимированный маршрут со стрелками.
- Framer Motion (LazyMotion) и Lenis, с учётом `prefers-reduced-motion`.
- vite-plugin-pwa: офлайн, установка на телефон, кэш тайлов карты.
- TomTom — по желанию (`VITE_MAP_PROVIDER=tomtom`, нужен ключ с доступом к API).

## Скрипты

| Команда | Что делает |
| --- | --- |
| `npm run dev` | dev-сервер на :5173, прокси `/api` |
| `npm run build` | проверка типов и сборка в `dist/` |
| `npm run build:django` | сборка в `../frontend_dist` для Django на Render |
| `npm run preview` | предпросмотр сборки на :4173, прокси `/api` |
| `npm run geocode:osm` | геокодирование 50 официальных пунктов (Nominatim) |
| `npm run points:find` / `points:apply` | поиск объектов OSM для пунктов «на проверке» и сверка района |
| `npm run houses` | сборка списка домов из OpenStreetMap с маршрутами |
| `npm run houses:routes` | пересчёт запасных маршрутов домов |

Скрипты данных (`scripts/*.ts`) запускаются в Node.js 22.18+ без сборки.

## Переменные окружения

Всё необязательно, см. [`.env.example`](.env.example).

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `VITE_API_URL` | `/api` | адрес API |
| `VITE_DEV_API_PROXY` | `https://hackathon-base.onrender.com` | куда `npm run dev` проксирует `/api` |
| `VITE_MAP_PROVIDER` | `osm` | `osm` / `tomtom` / `tomtom-orbis` |
| `VITE_SEARCH_PROVIDER` | `osm` | `osm` / `tomtom` |
| `VITE_ROUTING_PROVIDER` | `osm` | `osm` / `tomtom` |
| `VITE_TOMTOM_KEY` | — | ключ TomTom, если выбран `tomtom` |
| `VITE_USE_MOCKS` | `true` | тревога только демо |
