# API-контракт фронтенда «Готов к толчку»

Документ описывает, **какие эндпоинты и форматы ответов ожидает фронтенд** от бэкенда.
Пока бэкенда нет — фронтенд работает на моках (`src/mocks/`) и эвристиках. Когда
появятся реальные эндпоинты, достаточно переключить окружение — код трогать не нужно.

## Как фронтенд обращается к данным

Весь доступ к данным изолирован в слое [`src/api/`](src/api). Переключение
мок/реальный API — через переменные окружения (`.env`):

```env
VITE_USE_MOCKS=false                 # true — моки, false — реальный бэкенд
VITE_API_URL=http://127.0.0.1:8000/api
```

- `VITE_USE_MOCKS=true` (по умолчанию) — данные берутся из `src/mocks`, бэкенд не нужен.
- `VITE_USE_MOCKS=false` — фронтенд делает GET-запросы на `VITE_API_URL + <path>`.

Все ответы — JSON. Ожидается заголовок `Content-Type: application/json`.
Нужен **CORS** для домена фронтенда (в dev — `http://localhost:5173`).
Для Django удобно `django-cors-headers`.

## Типы данных

TypeScript-интерфейсы — источник истины: [`src/api/types.ts`](src/api/types.ts).
Ниже — то же самое в виде JSON.

### AssemblyPoint — пункт сбора / открытая площадка

```jsonc
{
  "id": "cpkio",                       // string, уникальный
  "name": "Центральный парк культуры и отдыха",
  "type": "park",                      // park | stadium | square | field | schoolyard | other
  "district": "Медеуский",             // необязательно
  "address": "ул. Гоголя, 1",          // необязательно
  "lat": 43.2637,
  "lon": 76.9573,
  "capacity": 15000                    // необязательно, чел.
}
```

### House — дом и оценка сейсмориска

```jsonc
{
  "id": "opt-123",                     // необязательно
  "address": "проспект Абая, 10",
  "lat": 43.2418,
  "lon": 76.9468,
  "floors": 9,                         // number | null
  "yearBuilt": 1978,                   // number | null
  "buildingType": "Панельный",         // необязательно
  "risk": "high",                      // low | mid | high
  "riskScore": 72,                     // 0..100 — для шкалы
  "riskReason": "Высокий риск: дом старше актуальных сейсмонорм…",
  "estimated": true                    // true — оценка эвристикой, не по реестру
}
```

### FamilyMember — член семейного круга

> Сейчас хранится **только в localStorage** (бэкенд не требуется). Эндпоинты ниже —
> опциональны, для будущей синхронизации между устройствами.

```jsonc
{
  "id": "a1b2c3",
  "name": "Мама",
  "phone": "+7 701 123 45 67",
  "isSelf": false,                     // true — карточка самого пользователя
  "status": "safe",                    // safe | no_contact | unknown
  "updatedAt": "2026-09-22T15:02:00Z"  // ISO 8601
}
```

### Alert — событие тревоги (землетрясение)

```jsonc
{
  "id": "evt-2026-09-22-01",
  "active": true,
  "startedAt": "2026-09-22T15:00:00Z",
  "title": "Землетрясение!",
  "message": "Немедленно выйдите на открытое пространство",
  "magnitude": 5.8,                    // необязательно
  "source": "mchs",                    // demo | mchs | sensor
  "recommendedPointId": "cpkio"        // необязательно, id пункта сбора
}
```

## Эндпоинты (нужны фронтенду сейчас)

### `GET /assembly-points/`

Список всех пунктов сбора.

- **Ответ 200:** `AssemblyPoint[]`
- Вызывается на экране «Карта» и «Семья».

```jsonc
[ { "id": "cpkio", "name": "…", "type": "park", "lat": 43.26, "lon": 76.95 }, … ]
```

### `GET /house/?lat={lat}&lon={lon}&address={address}`

Данные о доме и оценка риска по координатам/адресу.

- **Параметры:** `lat` (float), `lon` (float), `address` (string, URL-encoded).
- **Ответ 200:** `House`
- Если реальных данных по зданию нет — верните оценку и `"estimated": true`.

### `GET /alert/active/`

Активная тревога, если есть.

- **Ответ 200:** `Alert` **или** `null` (когда тревоги нет).
- Фронтенд опрашивает этот эндпоинт (polling) или, в будущем, слушает websocket.
  В демо-режиме тревога поднимается вручную кнопкой и этот эндпоинт не вызывается.

## Эндпоинты (опционально, на будущее)

Семейный круг и чек-лист сейчас живут в localStorage. Если понадобится
синхронизация/оповещение через бэкенд — предлагаемый контракт:

| Метод и путь                     | Тело / параметры                    | Ответ            |
| -------------------------------- | ----------------------------------- | ---------------- |
| `GET /family/`                   | —                                   | `FamilyMember[]` |
| `POST /family/`                  | `{ name, phone }`                   | `FamilyMember`   |
| `PATCH /family/{id}/`            | `{ status }`                        | `FamilyMember`   |
| `DELETE /family/{id}/`          | —                                   | `204`            |
| `POST /alert/{id}/checkin/`     | `{ memberId, status: "safe" }`      | `200`            |

---

## Коды ошибок

Фронтенд считает ответ успешным при `2xx`. При `4xx/5xx` показывает состояние
ошибки и не роняет приложение. Тело ошибки может быть любым JSON —
фронтенд его не парсит, ориентируется на статус.

## Замечания по данным

- Координаты пунктов сбора в моках — реальные открытые площадки Алматы, значения
  приблизительные. На проде замените на выверенные из реестра/ГИС.
- Оценка риска дома в моках — **эвристика** (`src/lib/risk.ts`), не официальные данные.
  Реальный `GET /house/` должен возвращать данные из достоверного источника.
- Поиск адреса идёт напрямую в Nominatim (OpenStreetMap) с фронтенда и бэкенда не
  требует. При желании его можно проксировать через бэкенд (кэш, лимиты).
